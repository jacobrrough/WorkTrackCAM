WORKFLOW H — CAD SELECTION SYSTEM (3 build agents, 20 min)
----------------------------------------------------------------------

CAD V1 — entity tagging during tessellation
  engines/cad/cadquery_script.py — new tessellate_with_face_ids
  (handle, *, tolerance_mm=0.1) walks solid.Faces(), calls
  face.tessellate(tol) per face, concatenates per-face vertices/
  indices into flat global buffers while tracking which triangle
  came from which face. Returns vertices/indices/faceIds (parallel
  array of length triangleCount) + bbox + faceMap (dict keyed by
  faceId with kind/occtHash/area).
  - _safe_face_hash reads OCCT TopoDS_Face.HashCode() with
    graceful fallback to 0 if OCP binding does not expose it
    (tries 3 increasingly-conservative upper bounds).
  - _safe_face_area reads face.Area() with 0.0 fallback so a
    single bad face does not kill whole tessellation.
  - Per-face degenerate-triangle filtering matches existing
    binary-STL writer (Safety Rule 1 parity).
  - Best-effort _tessellate_with_face_ids_for_handle() invoked
    inside execute_script so each mesh entry ALSO carries faceIds +
    faceMap — backward compatible (STL path unaffected).

engines/sidecar/cad_handlers.py — new tessellate_with_ids handler
validates handle (REQUIRED) and optional toleranceMm. Registered
in HANDLERS so cad.tessellate_with_ids is dispatchable.

src/shared/sidecar-protocol.ts — wire types for
  cad.tessellate_with_ids (flat vertices/indices/faceIds arrays,
  triangleCount, bbox, faceMap: Record<string, CadFaceMapEntry>);
  CadFaceMapEntry (kind: 'face', occtHash: number, optional area).
  CadExecuteScriptMesh extended with optional faceIds + faceMap.
